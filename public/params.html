Knob layout

Each OP-1 Field patch embeds a JSON blob in an AIFF-C container: the synth engine, one envelope (ADSR for most synths; dyna_env for dbox), one FX and one LFO, each a fixed 8-element array of 16-bit integers. Every card names the parameter behind each array index, colored by how its raw value reads on screen. See Value mappings for the raw-to-display detail.
